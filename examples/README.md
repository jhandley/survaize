# Example Survey/Census Questionnaires

These are example questionnaires used for testing. All are either publicly available or created for testing purposes.

## Example Questionnaires
- PopstanHouseholdSurvey: A simple test questionnaire designed to test the system.

- [Ghana Population and Housing Census 2021](https://census2021.statsghana.gov.gh/resources.php?readpage=MjM0ODgzNjQxMy41MDg1&Instruments-and-training-materials)
- [Japan National Survey of Family Income, Consumption and Wealth 2019 Household Questionnaire](https://www.stat.go.jp/english/data/zenkokukakei/questionnaire.html)
- [Slovenia 2002 Census Questionnaire for Dwellings](https://unstats.un.org/unsd/demographic/sources/census/quest/SVN2002enHs.pdf)
- [PMA Phase 3 Household Questionnaire (French)](https://www.pmadata.org/data/survey-methodology)
- [World Bank COVID-19 Impact on Firms](https://www.enterprisesurveys.org/en/covid-19)
